# Runtime regression migration

The faithful root interface preserves upstream syntax records. Existing regression
fixtures remain useful, but lowercase fields, omitted defaults, invented auxiliary
ranges, and UTF-16 locations are no longer the intended public result.

`regression-helpers.ts` is private test infrastructure for structural enumeration
and byte slicing. It makes no public traversal API claim. Expected node types,
field sets, scalar values and literal text come from pinned upstream source or
hand-specified fixtures, not from enumerating the generator output as an oracle.

## Validation observations

The original 13 runtime suites were captured before editing: 149 failures and 92
passes with the starting five-field runtime/six-field binary mismatch. Replaying
those unchanged tests against the consistent six-field runtime and Linux binary
produced **148 failures and 93 passes** across 241 tests (11 failing suites, two
passing). This separates the API migration failures from the temporary mismatch.

The migrated suites pass **218 tests across all 13 suites**. Differences in test
count reflect removal of obsolete private-normalizer/envelope assertions and
consolidation of duplicate shape checks, as mapped above. The full depth and
dialect matrices are retained. A focused TypeScript check includes every migrated
runtime file with the package root as rootDir; focused ESLint and Prettier checks
also pass. The scalar type suite passes against the generated public API rollup.

These observations use the supervisor's Linux-built six-field WASM artifact.
They are local integration evidence, not a publication or CI claim. The artifact
is not part of the test-migration commit. The unchanged broad test tsconfig cannot
be used directly as a scoped type gate: its rootDir excludes imported src files,
and unrelated analyze tests were still migrating when this work was performed.
